🚀 Project Overview

TaskFlow is a modern task management application that demonstrates best practices in DevOps and CI/CD automation. The application is built with HTML, CSS, and JavaScript, containerized using Docker, and deployed automatically using GitHub Actions and Render.

🛠️ Tech Stack

  • 🎨 Frontend: HTML5, CSS3
  • 📦 Build Tool: Parcel
  • 🐳 Containerization: Docker & Docker Compose
  • ⚡ CI/CD: GitHub Actions
  • 🌐 Deployment: Render
  • 🔍 Linting: HTMLHint, Stylelint

📖 How to Use TaskFlow

  1. 📝 Create Tasks: Use the "Add Task" page to create new tasks
  2. 📋 View Tasks: Browse your task list on the Tasks page
  3. ✅ Complete Tasks: Mark tasks as complete when finished
  4. 👤 Manage Profile: Update your preferences in Profile
  5. 📊 Track Progress: Monitor your completion rate
